How to read this radar

Implied value is what a protocol's token could be worth at launch, built only from this snapshot's own figures: its TVL times its category's FDV/TVL multiple — the median market-cap-to-TVL ratio of the live-token protocols in the same category, in this same snapshot — times a growth factor from its 7-day TVL change (clamped −50% to +150%, half weight), times a maturity factor that grows with how long it has run with no token (diminishing, capped at three years), times a small bonus for running on more chains. No name is ever special-cased. Click any row to see its exact factors.

“Records no token” is the snapshot's own wording: the protocol's record carries no market cap, no CoinGecko id and no symbol. The board ranks only such protocols. Protocols that already trade sit in the Live token market view with the market's own values, never a model's.

Set aside: rankable protocols sit at or above the $50M watchlist floor but the watchlist leaves them out — wrapped, staked and bridged products of tokens that already trade, and exchange products. They are listed, not hidden, in the Set aside view.
